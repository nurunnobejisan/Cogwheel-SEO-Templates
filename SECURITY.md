# Security Policy

See [`docs/SECURITY.md`](docs/SECURITY.md) for the full policy, including
supported versions, reporting process, and runtime security controls
(authentication, SSRF egress validation, rate limiting, CSRF, local bridge
gating, and data-provenance rules).

**Do not report vulnerabilities in public issues.** Use GitHub private
vulnerability reporting (`Security` tab → `Report a vulnerability`) or contact
the maintainer privately.
